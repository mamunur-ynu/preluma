# Preluma

Light Up Before Class.

Preluma is a pre-class learning assistant that helps students enter lectures prepared, confident, and ready to ask better questions.

## Core experience

- Brain Brief
- Pre-class Quiz
- Mistake Clinic
- Ask Me Tutor
- Concept Map
- Class Questions
- Readiness Dashboard
- Teacher Studio

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy

Upload these files to GitHub and deploy with Streamlit Cloud:

- streamlit_app.py
- engine.py
- topics.py
- teacher.py
- requirements.txt
- README.md

Main file path:

```text
streamlit_app.py
```
